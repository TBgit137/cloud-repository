### Part 3

Track B 已完成，覆盖四种执行环境：

- `[native-x86]`：TFLite PTQ INT8。
- `[QEMU-CM]`：qemu-arm Cortex-M3 + TensorFlow Lite Micro。
- `[WebGPU-proxy]`：ONNX Runtime Web 1.23.2 + WebGPU 桌面代理。
- `[modeled-ARM]`：Cortex-A78 解析估算，不是实测。

最终保存结果：

- native x86 PTQ：0.663 ms。
- QEMU Cortex-M PTQ：946 ms；100 Hz 时钟，精度 10 ms，5 次平均。
- WebGPU proxy：均值 4.907 ms、中位数 5.0 ms、P95 6.1 ms，100 次。
- Cortex-M 模型：982,152 bytes。
- TFLite Micro arena 实际使用：707,028 bytes。

重要结论：

- 模型可以放入假设的 2 MiB flash。
- arena 超过假设的 512 KiB SRAM，因此不能声称可部署到该 SRAM 配置。
- QEMU user mode 只证明功能执行，不执行物理 SRAM/flash/cache/thermal 限制。
- QEMU 时间会波动，观测过约 934–950 ms；最后一次正式保存值是 946 ms。重新运行会有小幅变化。
- WebGPU 是桌面 GPU 代理，不是手机实测。
- 作业允许 QEMU-CM 替代 Renode，因此没有安装 Renode 不算缺项。
