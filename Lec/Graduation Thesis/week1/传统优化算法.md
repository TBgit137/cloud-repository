# 关于飞机跑道优化问题的传统优化算法探索

## 传统优化算法收录

### 数学规划方法：
- 1. 线性规划(Linear Programming, LP)：
    - 在给定一组线性等式和不等式约束条件下，最大化或最小化一个线性目标函数的数学优化问题。
    - 核心特征： 目标函数和所有约束条件中，决策变量 $x_i$ 的指数都为 1。
    - 问题形式： $\min / \max \quad c^T x$ 满足 $A x \leq b$ 且 $x \geq 0$
    - 适用范围： 目标函数和所有约束条件都必须是线性的。
    - 举例：假设一个工厂生产两种产品 $x_1$ 和 $x_2$，目标是最大化利润 $Z = 3x_1 + 2x_2$，同时受到两种资源（机器时间 $R_1$ 和人力 $R_2$）的限制：
        - 目标函数 $Z = 3x_1 + 2x_2$ (利润)
        - 约束 $R_1$ ： $x_1 + 2x_2 \leq 6$， $R_2$：$2x_1 + x_2 \leq 8$， $x_1 \geq 0, x_2 \geq 0$
    - 求解算法：单纯形法 (Simplex Method)
        - 算法流程：
            - 1. 标准化： 将不等式约束转化为等式（引入松弛变量）。
            - 2. 顶点搜索： 从可行域的一个初始顶点开始（找到一个基可行解）。
            - 3. 迭代： 系统地检查相邻的顶点。如果移动到相邻顶点能改善目标函数值，则进行旋转操作 (Pivoting)。
            - 4. 终止： 重复此过程，直到当前顶点无法再通过移动来改善目标函数值，找到全局最优解。
    - 保证找到全局最优。单纯形法在实践中非常高效。

- 2. 整数规划(Integer Programming, IP)：
    - 在所有决策变量都必须取整数值的约束下，最大化或最小化一个线性目标函数的数学规划问题。也就是有整数约束的线性规划问题。
    - 有三类：
        - 纯整数规划 (Pure IP): 所有变量都要求是整数。 
        - 混合整数规划 (Mixed IP, MIP): 部分变量要求是整数，部分可以是实数。 
        - 0-1 整数规划 (Binary IP): 变量只能取 0 或 1，常用于建模是/否决策、选择或分配问题。
    - 举例：一个容量有限的背包，要从一系列物品中进行选择，以最大化物品的总价值。
        - 目标函数：最大化总价值
        - 决策变量：$x_i$ 能取 0 或 1，选择物品或者不选
        - 约束：总重量限制
    - 求解算法：分支定界法 (Branch and Bound, B&B)
        - 算法流程：
            - 1. 松弛 (Relaxation): 忽略整数约束，将 IP 转化为一个容易求解的 LP 问题（LP 松弛）。
            - 2. 定界 (Bounding): 求解 LP 松弛问题得到一个最优值，该值是 IP 最优值的上限（最大化问题）。
            - 3. 分支 (Branching): 如果 LP 解中的整数变量不满足整数约束（如 $x_i=1.5$），则将问题分解为两个子问题（例如 $x_i \leq 1$ 和 $x_i \geq 2$）。
            - 4. 剪枝： 使用已知的可行整数解作为下限，如果某个子问题的上限低于这个下限，则剪除该分支，不再搜索。重复此过程直到所有分支都处理完毕。
        - 本质上是一种智能的、有组织的穷举搜索方法。
    - 保证全局最优解（如果计算时间足够）。计算难度高，解空间呈指数级增长，对大规模问题难以在合理时间找到精确解。可行域是一系列离散点，不能使用基于梯度的连续优化方法。

- 3. 非线性规划(Nonlinear Programming, NLP)：
    - 目标函数 $f(x)$ 或约束条件 $g(x) \leq 0, h(x) = 0$ 中至少有一个包含非线性表达式的数学优化问题。
    - 核心特征： 目标函数或约束中包含 $x^2, \sin(x), x_1 x_2$ 等非线性项。
    - 问题形式： $\min / \max \quad f(x)$ 满足 $g(x) \leq 0$ 且 $h(x) = 0$
    - 举例：
        - 一家公司在做投资组合优化，目标是最大化回报，同时最小化风险（用方差衡量）。
        - 目标函数：最小化风险（方差），方差通常是投资权重 $x_i$ 的二次函数（例如 $x_1^2 + x_2^2 + 2\rho x_1 x_2$），这使得目标函数为非线性的。
        - 决策变量：$x_i$投入不同资产的资金比例（实数）。
        - 约束：总投资比例为 1
        - 核心挑战：局部最优 非凸的非线性规划问题可能存在多个局部最优解，算法通常只能找到离起点最近的局部最优解。
    - 求解算法：牛顿法 (Newton's Method)：
        - 针对于最常见的无约束非线性规划 $\min f(x)$
        - 算法流程：
            - 1. 二次近似： 在当前点 $x_k$ 处，用一个二次函数（利用一阶梯度和二阶海森矩阵）来近似目标函数 $f(x)$。
            - 2. 一步到位： 直接计算并跳到这个二次近似函数的最低点，确定新的搜索方向 $d_k = - H_k^{-1} \nabla f(x_k)$。
            - 3. 迭代： 通过迭代公式 $x_{k+1} = x_k + d_k$ 快速收敛到局部最优解。
    - 局部最优（不保证全局）。需要计算和处理一阶导数（梯度）和二阶导数（海森矩阵），计算量和复杂度高于 LP。依赖于梯度信息（如梯度下降法）和曲率信息（如牛顿法、拟牛顿法）进行迭代搜索。

### 梯度优化算法：
- 1. 梯度下降法 (Gradient Descent, GD)：
    - 一种用于寻找函数局部极小值的一阶迭代优化算法。
    - 核心思想： 基于泰勒展开，确定目标函数在当前点下降最快的方向是负梯度方向。算法通过沿着这个方向迈出一步（步长由学习率决定），迭代地更新参数，直到收敛到局部最优解。
    - 迭代公式： $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ 其中 $\alpha_k$ 是步长（或学习率），$\nabla f(x_k)$ 是函数在 $x_k$ 处的梯度。
    - 举例：优化一个简单的二次函数 $f(x) = x^2 - 4x + 7$，其最小值为 $x=2$ 处。
        - 目标函数 $f(x)$
        - 梯度$\nabla f(x)$：$f'(x) = 2x - 4$
        - 负梯度：$- (2x - 4)$
        - 学习率 $\alpha$：0.1（假设）
        - 迭代过程：1. 设 $x_0=5$。 2. $\nabla f(5) = 10 - 4 = 6$。 3. $x_1 = 5 - 0.1 \times 6 = 4.4$。
    - 求解算法：梯度下降法 (Gradient Descent)：
        - 算法流程：
            - 1. 初始化： 选取一个初始点 $x_0$ 和学习率 $\alpha$。
            - 2. 计算方向： 计算当前点的负梯度 $-\nabla f(x_k)$ 作为下降方向。
            - 3. 更新： 沿该方向移动一步：$x_{k+1} = x_k - \alpha \nabla f(x_k)$。
            - 4. 循环： 重复步骤 2 和 3，直到满足终止条件（如梯度足够小或迭代次数达到上限）。
    - 仅依赖一阶导数（梯度），计算简单，内存开销小。具有线性收敛速度。在山谷狭长（病态条件数）时，容易出现“锯齿形”振荡，收敛慢。鲁棒性高。对学习率 $\alpha$ 敏感。

- 2. 共轭梯度法 (Conjugate Gradient Method, CG):
    - 一种用于求解正定二次型无约束优化问题（即目标函数是正定二次函数）的迭代算法，同时也是求解大型线性方程组 $A x = b$ 的有效方法。
    - 核心思想： CG 法不沿着简单的负梯度方向（如梯度下降），而是沿着一组共轭方向 (Conjugate Directions) 进行搜索。这些方向是相互Q-共轭的，能保证每次迭代都在一个新的、独立的维度上找到最优值，从而避免了梯度下降中常见的“之字形”震荡。(Q-共轭： 两个方向 $d_i$ 和 $d_j$ 满足 $d_i^T Q d_j = 0$（其中 $Q$ 是目标函数的海森矩阵）。)
    - 举例：在一个狭长的椭圆形山谷（由二次函数定义）中找到最低点。
        - 梯度下降 (GD)：沿着垂直于等高线（椭圆）的方向走。路径是锯齿形的，收敛慢。
        - 共轭方向 $d_k$ 沿着椭圆的长轴和短轴方向（或与它们相关的一组独立方向）。
        - 共轭方向的优点：消除依赖，沿着一个共轭方向找到的最优解，沿着下一个共轭方向搜索时，不会破坏前一个方向上已经取得的进步。
        - 理论收敛性$n$：n步收敛
    - 求解算法：共轭梯度法 (Conjugate Gradient)：
        - 算法流程：
            - 1. 初始化： 从初始点 $x_0$ 出发，将第一个搜索方向 $d_0$ 设为负梯度 $-\nabla f(x_0)$。
            - 2. 线搜索： 沿着当前方向 $d_k$ 找到最优步长 $\alpha_k$，更新 $x_{k+1}$。
            - 3. 计算新方向： 新的搜索方向 $d_{k+1}$ 是负梯度和前一个搜索方向的线性组合。这个组合确保了 $d_{k+1}$ 与之前所有方向都是 Q-共轭的。
            - 4. 迭代： 重复步骤 2 和 3，直到收敛。
    - 阶数介于一阶和二阶之间。计算开销低。保证全局最优解。收敛速度快。非常适合求解变量数量庞大的系统（内存和计算开销小）。

- 3. 拟牛顿法 (Quasi-Newton Methods)：
    - 一类用于求解无约束优化问题 $\min f(x)$ 的迭代算法。
    - 核心思想： 牛顿法需要计算和求逆精确的 海森矩阵 $H$（二阶导数），而拟牛顿法通过使用一阶梯度信息，构造一个易于计算的矩阵 $B$ 来近似海森矩阵 $H$ 或其逆 $H^{-1}$。
    - 迭代公式： $x_{k+1} = x_k - \alpha_k B_k^{-1} \nabla f(x_k)$ 拟牛顿法： $B_k \approx H_k$ (近似海森矩阵)
    - 举例：最小化二次函数 $min f(x_1, x_2) = x_1^2 + 2x_2^2$ 这是一个简单的二次凸函数，其最小值在 $\mathbf{x}^* = (0, 0)^T$ 处。目标是用拟牛顿法找到一个搜索方向 $\mathbf{d}_k$，使得迭代能快速收敛到 $(0, 0)^T$。
        - 从初始 $\mathbf{B}_0 = \mathbf{I}$ (单位矩阵) 开始。在每次迭代后，修正 $\mathbf{B}_k$ 矩阵，使其逐渐近似 $\mathbf{H}$，从而使搜索方向 $\mathbf{d}_k = -\mathbf{B}_k^{-1} \nabla f(\mathbf{x}_k)$ 越来越接近牛顿法的搜索方向，实现快速收敛。
    - 求解算法：BFGS 算法：
        - 算法流程：
            - 1. 确定搜索方向：使用当前的近似逆海森矩阵 $\mathbf{D}_k$ 和梯度 $\nabla f(\mathbf{x}_k)$ 来计算搜索方向 $\mathbf{d}_k$： $\mathbf{d}_k = -\mathbf{D}_k \nabla f(\mathbf{x}_k)$
            - 2. 线搜索确定沿 $\mathbf{d}_k$ 方向的最优步长 $\alpha_k$。
            - 3. 更新点移动到新的点： $\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{d}_k$。
            - 4. 更新近似矩阵这是 BFGS 的核心。 利用位移 $\mathbf{s}_k$ 和梯度变化 $\mathbf{y}_k$ 的信息，应用 BFGS 更新公式来修正 $\mathbf{D}_k$，得到 $\mathbf{D}_{k+1}$。
    - 比最速下降法的线性收敛要快得多，但略慢于牛顿法的二次收敛。即使初始点不好，通过配合线搜索和保持 $\mathbf{D}_k$ 正定性，通常也能确保收敛到局部最优解。适用于大规模问题：特别是 L-BFGS，由于其节省内存的特性，成为求解大规模无约束优化问题（如机器学习中的损失函数最小化）的首选算法之一。
